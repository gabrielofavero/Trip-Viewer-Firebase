# Archived PoC Files

This directory contains legacy proof-of-concept HTML templates from early development.

These files are **pre-migration artifacts** and still contain Portuguese (pt-BR) text, IDs, classes, and variable names. They are kept for historical reference only and are **not used in production**.

## Contents

- `html templates/` — Early UI mockups (destination cards, itinerary, hotel boxes, filtering, drag-and-drop, etc.)

## Migration Status

These files were archived during the English cleanup (E049: Final English Cleanup, Prompt 6). They were not translated because:
1. They are not referenced by any production code
2. They served as design exploration only
3. The production equivalents have already been fully translated

If any of these templates are needed in the future, translate them to English before use.
